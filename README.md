# Darts Score PWA
Application web progressive (PWA), pensée pour iPhone.
- Ouvrir l'URL du site en HTTPS dans Safari
- Partager → Sur l'écran d'accueil
- Lancer ensuite l'icône comme une application
- Après la première visite, les fichiers sont mis en cache pour le fonctionnement hors ligne.
Modes : 301, 501, 701, Cricket, Shanghai V.
